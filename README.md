## 📂 Topics Covered

- **SQL Fundamentals (SELECT & Filtering)**  
  - Retrieve data with `SELECT`  
  - Remove duplicates with `DISTINCT`  
  - Sort results using `ORDER BY`  
  - Limit rows with `LIMIT`  
  - Filter rows with `WHERE`, `AND`, `OR`, `NOT`, `IN`  

- **NULL Functions**  
  - Handle missing values with `COALESCE`, `ISNULL`, `IFNULL`  
  - Replace `NULL` with defaults (e.g., 0, "Not Assigned")  
  - Use `CASE` and `COALESCE` for flexible outputs  
  - Practical scenarios: employees, orders, students, products, payments  

- **Date Functions**  
  - Extract date parts (`DAYNAME`, `MONTHNAME`, `YEAR`, `QUARTER`)  
  - Format dates with `TO_DATE`, `TO_CHAR`  
  - Calculate differences with `DATEDIFF`, add intervals with `DATEADD`  
  - Find period boundaries (`DATE_TRUNC`, `LAST_DAY`)  
  - Classify dates with `CASE` (e.g., Weekend vs Weekday)
